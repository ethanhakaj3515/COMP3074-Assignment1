# COMP3074 Assignment 1 - Payroll Calculator

Native Android Java application with two activities:

- `MainActivity` calculates regular pay, overtime pay, total pay, and tax.
- `AboutActivity` displays Ethan Hakaj (student ID 101465282).

## Run the app

Open this folder in Android Studio, allow Gradle to sync, and run the `app` configuration on an emulator or Android device.

## Payroll rules

- Hours up to 40 are paid at the hourly rate.
- Hours above 40 are paid at 1.5 times the hourly rate.
- Tax is calculated on regular pay, following the assignment formula `tax = pay * tax_rate`.
- Enter the tax rate as a percentage (for example, enter `15` for 15%).
- Amounts display to two decimal places. The assignment does not specify a currency.
